DIAM 周报差异对比 v1.2

使用方法
1. 双击 DIAM-Weekly-Comparer.exe，无需安装 Python 或 Excel。
2. 顶部同一行选择上一周与本周文件，再点击「开始对比」。只读取各自第一个工作表，包含隐藏行。
3. 默认打开可视化总览：查看预计金额、净变化、客户增减排行和月份分配变化。
4. 点击排行客户，打开更大的数据明细区，查看逐字段前后数据与原始行号。
5. 团队、实体、销售类型和搜索同步影响总览与明细；「明细类型」仅筛选明细清单。
6. 数据提示独立展示，不影响阅读主要变化；原始工作簿保持不变。
7. 可导出交互 HTML 报告（浏览器离线打开）或 CSV 明细（Excel 打开）。导出包含全部数据变化，不受软件当前筛选限制；HTML 内可再次筛选。

比较口径
- 「预计金额」对应原表 Total（FCST）列，只改显示名称，不改变数据含义或金额。
- 按团队＋实体＋External/Group＋客户（Bill to）匹配，忽略大小写及多余空格。不同实体／团队／销售类型下的同名客户分别比较。
- 客户记录新增／删除、金额增加／减少、月份调整分别显示；身份字段改变显示为删除／新增。
- 只展示数据变化，不展示或导出公式差异；数值没变的公式调整不计入变化，Z／AA 每周参考滚动也不计入。
- 原有客户由 0 变正数不代表新增客户；金额归零不代表订单取消。
- 该汇总表没有订单号或 OB 状态，不能识别单笔订单的状态变更。
- 保留原表金额单位，不自行换算，不套用网站业务排除规则。
- 概览显示两位小数，明细和 CSV 保留来源精度。∅ 代表缺失，不是零。
- 合计使用全部客户记录，不使用会受到隐藏行影响的底部 Total。
- 缺少可用数值时提示，不用零补齐；不执行宏、刷新公式或外部链接。

运行与隐私
- Windows 10/11 64位，默认中文，添加 --lang en 可用英文。
- 完全离线，不联网、不上传、不修改原始文件、不向 Dashboard 发布。
- EXE 自带运行环境，首次启动可能需要几秒钟。
- HTML 与 CSV 含业务信息，请保存在合适的位置。
