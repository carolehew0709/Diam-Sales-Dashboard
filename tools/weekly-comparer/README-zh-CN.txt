DIAM 双页面周报对比 v3.0

快速开始（先解压，再运行）
1. 将 ZIP 中的全部文件解压到一个可写文件夹，不要直接在压缩包内双击程序。
2. 双击 DIAM-Weekly-Comparer.exe。软件无需安装 Python 或 Excel。
3. 比较两份周报，进入「两周对比」；持续保存多周数据，进入「连续性追踪」。
4. 首次使用连续性追踪，请导入周报并核对报表年和周次；以后可每周追加。
5. history 文件夹会在程序旁自动创建。换电脑或移动程序时，请连同 history 一起复制。

压缩包内容
- DIAM-Weekly-Comparer.exe：最新版双页面便携程序。
- 使用说明.txt：本说明，包含两个页面的操作方法、比较规则和本地历史管理。



两个页面
- 「两周对比」保留 v2 的匹配、数据、筛选、图表、逐行明细和导出，不会自动导入历史。
- 「连续性追踪」用于导入多份周报，查看项目逐周状态、RMB／USD／EUR 金额趋势和 Invoice Date，不设置停滞提醒。

连续性追踪使用方法
1. 点击「导入多份周报」，可以同时选择多个 .xlsx 文件。
2. 在清单核对每份文件的报表年、ISO 周次和来源行数。文件名仅用于预填。
3. 缺少年份时，可用「统一补充空缺年份」一次填写；双击文件可单独编辑年／周。
4. 同一周已有其他版本时，需在编辑窗口勾选允许替换；旧版本会保留。确认后整批保存，失败不留下半批。
5. 状态矩阵按项目为行、周次为列。默认最近12个日历周（不超出已有历史），只显示所选范围最新一期仍有的项目。
6. 可以切换全部历史项目、调整起止周、按 Team／Brand 和项目关键词筛选。
7. 点击项目显示三种金额的独立趋势、状态和 Invoice Date；点击周次可查看该周每条来源行。
8. 「未导入该周」「该周没有此项目」「筛选范围内无数据」「字段缺失」分别显示。不补前值，不填零，金额线遇到缺口断开。
9. 金额与日期中的 TBC 或文字说明保留原样；来源日期含时间时也会保留。
10. 「管理历史」可移出某周，或从版本清单恢复以前版本；原始工作簿不会被删除或改写。
11. 相同文件在相同周次重复导入不会新增。误设到其他周次时，先移出原记录再重新导入。
12. 连续性页面单独导出所选时间范围的 HTML / CSV。HTML 可继续筛选、点击周次并下载当前筛选清单。

本地历史与便携搬迁
- 历史保存在软件旁的 history/continuity.sqlite，不依赖原周报一直保留在原路径。
- 搬迁软件时，连同 history 文件夹一起复制，即可保留历史。
- 历史库和导出报告含私人业务数据。发布压缩包只包含程序和说明，不包含用户历史。
- 首次打开连续性页面没有历史时，请自行导入；示例 HTML 只演示已有 W44／W45，不虚构其他周次。

两周对比使用方法
1. 双击 DIAM-Weekly-Comparer.exe，无需安装 Python 或 Excel。
2. 顶部同一行选择上周、本周文件，点击「开始对比」。
3. 只读取名为 on-going-DDC 的工作表，不再比较第一个汇总表。
4. 总览显示变化、新增、从本表移出、两周状态相同的项目组数量。
5. 金额图可选 RMB / USD / EUR，三种币种分别比较；状态图显示实际状态转换。
6. 点击项目金额排行可查看来源逐行明细。点击「两周状态相同」区域即可打开该清单。
7. Team 和 Brand 可组合筛选；先筛来源行，再按项目汇总，不把其他 Brand 金额混入。
8. 查看条件可选：有数据变化、状态相同、状态变化、Invoice Date 变化、金额变化、新增、移出、待核对或全部。
9. 导出 CSV 为当前筛选的清单，Team、Brand 在前两列，可在 Excel 内继续筛选。
10. 导出的 HTML 可以离线按 Team / Brand / 查看条件筛选，并下载筛选后的 CSV。

比较规则
- 先按 E列 Job Number 匹配；该项目号任一周有多行时，使用 K列 Project Name 区分。
- 同号同名仍有多行时，作为一个项目组，保留所有行；金额按币种汇总，不按行号猜测配对。
- 重点比较 N列 RMB、O列 USD、P列 EUR，T列 Invoice Date 与 L列状态。
- 不比较公式文本、其他列变化或其他 sheet，不把三个币种相加，不自行换算汇率。
- 状态保留来源原文，不自动纠正 Production / Porduction 等拼写，也不把 PO 推断为另一种状态。
- 同组状态与日期会核对各值及出现次数，不仅比较某一条；所有逐行状态、日期和金额都可展开查看。
- 两周状态相同只表示这两份文件的非空状态一致。金额和日期仍可能变化，不推断更久的持续时间。
- 空白或 TBC 状态不算状态相同。金额空白、TBC、缺少可用数值均不补成零。
- 混合已知和未知金额时，显示已知部分及未知标记，不生成虚假的金额差额。
- 缺少项目号，或重复项目号缺少项目名时，保留为待核对，不假造新增、移出或状态相同。
- 「从本表移出」不代表项目取消；可能转到其他 sheet，本软件不自动推断去向。
- Project Name 只在项目号重复时用于匹配，不做模糊匹配。

运行与隐私
- 完全本地、离线运行，不修改源文件、不上传、不向 Dashboard 发布。
- 程序旧版本可清理；原始周报不改写，历史库内的周报版本仍可恢复。导出含业务资料，请按公司要求保存。
- 支持 Windows 10/11 64位。默认中文；命令行 --lang en 可用英文。
